# NIFTY Midcap ETL Analysis

A beginner Data Engineering project using Python, PostgreSQL, Git, and NSE market and financial data.

## Objective

Build an ETL pipeline that combines daily NSE market data with quarterly and annual financial data for selected NIFTY Midcap 100 stocks.

## Stock Universe

The project uses the top 10 NIFTY Midcap 100 stocks from the March-end 2026 benchmark snapshot, with the source factsheet dated March 31, 2026.

## Technologies

- Python
- PostgreSQL
- SQL
- Git
- GitHub
- Ubuntu
